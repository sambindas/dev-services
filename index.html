Add a service

Choose a project command or an existing Docker container. Saving does not start it.

Commands run with your user account's permissions. Only add commands you trust. The dashboard does not install project dependencies.

Set up your first service

1. Prepare your project

Install its runtime (such as Node, Python, PHP, or .NET) and dependencies. Verify that its start command works from the project folder in a terminal.

2. Add it to the dashboard

Choose Add service → Project command. Enter an absolute folder path, the working start command, and the port it listens on. Save, then select Start.

For Node, try npm run dev -- --port 3000 if your framework supports it. For a simple Python folder server, use python3 -m http.server 8000 on macOS/Linux or python -m http.server 8000 on Windows.

3. Or connect a Docker container

Install and start Docker. Create a container with a published host port, then add its existing name and host port here. The dashboard starts and stops containers; it does not create or delete them.

Platform details

Windows commands use cmd.exe. macOS/Linux commands use your configured shell. If a command needs nvm or another version manager, load it in the start command or use an absolute executable path. Relaunch after installing new tools.

Troubleshooting

Check Logs after a failed start. A port conflict means you need another port or must stop the existing process. Processes started outside the dashboard must first be stopped in their original terminal. Stop services before editing or removing them.

Your configuration and logs stay on this computer. Closing the browser leaves the dashboard running. Quit dashboard stops its controller; managed services keep running and reconnect when you reopen it.
